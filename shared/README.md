# Shared data

`timezones.bin` — time zone boundaries for offline lookup (docs/protocol.md §4.6), built by
`tools/build_tz.py` from [timezone-boundary-builder](https://github.com/evansiroky/timezone-boundary-builder)
release 2026f ("with oceans"), simplified to 0.005°.
